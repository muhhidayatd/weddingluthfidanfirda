UNDANGAN NIKAHAN ONLINE — RAKA & AISYAH

Cara menjalankan:
1. Buka index.html di browser.
2. Untuk GitHub Pages, upload index.html, style.css, script.js ke repository.
3. Edit data pada index.html.
4. Edit tanggal countdown pada script.js.
5. Untuk musik, tambahkan file music.mp3 dan isi atribut src pada tag audio di index.html.

Semua data saat ini adalah template/dummy.
